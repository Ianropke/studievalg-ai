# Jobs

Career claims require identified CV/user/document evidence, exact period and role; never infer missing tenure, headcount or achievements. Discovery of a job is not application submission. A recorded submission is not employer receipt, interview or outcome. Preserve these as separate fields with separate evidence. Sending requires explicit user authorization for the actual complete application, handled by the host outside this data validator. Protect personal source material. `examples/jobs.json` concerns a fictional person and supplies no career evidence about Ian.

Host acceptance: test the stated domain invariants at the actual consumer boundary. The general validator does not automatically implement all domain-specific rules.
